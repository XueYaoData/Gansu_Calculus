# Ancient dental calculus from Gansu, China

This repository is for the analysis of ancient oral microbiome data from the Hexi Corridor, China. It contains the scripts used for data processing, analysis, and visualization, as well as the configuration files used for Bayesian phylogenetic analyses in BEAST.

## Overview of the repository

- **01-Scripts/**: Scripts for sample processing and downstream analyses.
- **02-Configuration_files/**: Configuration files used for Bayesian phylogenetic analyses in BEAST.
